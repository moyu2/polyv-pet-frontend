# 狗狗桌宠 v2 实现说明

狗狗桌宠使用 Canvas 逐帧素材与独立动作编排。三个阶段复用同一组接口和组件，宠物选择器使用轻量封面。

## 本地查看

安装依赖并运行 `npm run dev` 后，打开 `http://localhost:15021/pet-preview.html`。预览复用正式组件，使用开发入口的演示接口；该入口不进入生产构建。

## 交互设计

- 手动拖放的位置优先保留，只限制视口边缘；窗口变小时收回到最近边缘，自动闲逛继续避开业务区域。
- 喂养面板中的滑杆支持 100%～250% 大小调整，本地保存偏好。缩放固定脚底锚点，不重新开始当前动作。
- 拖拽、隐藏、成长中断和迟到响应均通过动作令牌收敛到最新阶段；接口失败和幂等响应不重播奖励。

## 已实现

| 内容 | 当前行为 |
| --- | --- |
| 素材 | 三阶段透明 WebP 图集，每阶段 74 个姿态，共 222 个；9 组动作加 16 个注视方向 |
| 角色 | 采用最终 v3 母版制作，已按两次反馈拉开阶段差异并修正少年犬过瘦的问题 |
| 动画 | Canvas 裁帧、可变帧时长；动作完成事件推进主流程；停止整张 SVG 的浮动和挤压 |
| 行走 | 朝向与迈步相配，位移速度 34 CSS px/秒；只沿当前安全地面线短距离移动 |
| 注视 | 16 向眼睛与头颈姿态，中心死区和扇区滞后；远离指针后恢复待机 |
| 拖拽 | Pointer Capture，6 px 区分点击；悬空收爪姿态；允许拖放到整个视口并保留用户位置，只限制屏幕边缘；取消、失焦和捕获丢失时清理 |
| 喂养 | 成功后立即更新真实余额与经验，旧阶段吃完，再过渡到新阶段并开心；流程结束前禁用重复喂养 |
| 成长素材准备 | 进食时并行预加载下一阶段，最多缓存一张；有界等待，失败后使用对应狗狗封面，不锁住操作 |
| 异常 | 幂等响应不重播；失败不播放成功奖励；拖动、隐藏或卸载打断后收敛到最新阶段 |
| 信息 | 点击展开积分、经验、饱食和食物，常态突出狗狗；支持键盘打开和 Escape 关闭 |
| 显示偏好 | 收起与唤回，收起偏好保存在本机；减少动态效果模式保留静态形象和数值反馈 |
| 页面适配 | 观察真实播放器、聊天栏和输入区边界；无安全空间时显示唤回入口；手机停止自主游走；全屏时隐藏暂停 |

## 素材组织

[最终三阶段母版](./dog-growth-master-v3.png)与[资源清单](../public/assets/pets/v2/manifest.json)一同保留。图集采用 `polyv-pet/2` 元数据、8 列 × 11 行、单格 256 × 224 像素。

每张图集解码约 19.25 MiB。正式组件持有当前图，成长期间有界预加载下一张；预览页同时展示三个阶段，内存占用更高。

原始生成图与一次性验收结果仅留在本地，运行时使用 WebP 图集、封面和清单。素材拼装和验证脚本需要 Pillow、NumPy。

## 文件职责

- `pet-desktop-pet.vue`：SDK 身份与业务初始化接入。
- `pet-companion.vue`：正式宠物交互、喂养气泡与生命周期。
- `pet-canvas.vue`：裁帧、播放时钟、静态封面与减少动态效果。
- `pet-sprite.vue`：宠物选择器中的轻量狗狗封面及其他物种入口。
- `pet-legacy-sprite.vue`：保留其他已上架物种原有形象。
- `pet-animation.ts`：动作链、显示阶段、完成令牌及取消。
- `pet-motion.ts`：停靠、路径检查和 16 向注视。
- `pet-assets.ts`：清单、版本化资源加载和有界预加载。
- `use-pet-store.ts`：服务端数据；修复状态刷新覆盖新喂养结果的竞争，不再用动画计时器驱动界面。
- `scripts/assemble_dog_sprites.py`、`scripts/verify_dog_sprites.py`：确定性拼装和素材 QA，需要 Pillow 与 NumPy。本轮使用 Codex 自带 Python 运行时。
