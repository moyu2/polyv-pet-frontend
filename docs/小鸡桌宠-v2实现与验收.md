# 小鸡桌宠 v2 实现说明

沿用狗狗桌宠的 Canvas 逐帧播放器，将已制作完成的 `chicken-v2` 素材接到正式观看页及宠物选择器。三阶段为宠物蛋、雏鸡、母鸡，每阶段 74 帧，包含九组动作及 16 个注视方向。

## 实现

- `pet-assets.ts` 按物种选择目录和缓存清单：狗狗仍用 `v2`，小鸡用 `chicken-v2`。预加载使用完整资源地址匹配，避免同名文件串用；取消后迟到的清单不会重新创建预加载图片。
- `pet-canvas.vue` 为小鸡启用逐帧播放、透明点击区域和减少动态效果支持。异步加载只应用当前物种、阶段的结果；失败时按同阶段封面、同物种 SVG 顺序回退。
- `pet-companion.vue` 在小鸡成长时预加载下一阶段，保留先吃完、再成长的顺序。兼容最新的食物图片和面板内缩放滑杆。
- `pet-sprite.vue` 在选择器中展示小鸡三阶段新封面；封面失败时保留原有同物种形象。
- 本地演示入口 `/pet-preview.html?species=chicken` 复用正式组件，支持动作和成长预览。演示接口只存在于开发入口。


## 本地检查

启动前端后，可打开 `http://localhost:15021/pet-preview.html?species=chicken` 查看三阶段与成长动作。

```bash
node scripts/check-pet-assets.cjs
npm run check:pet
npm run check:pet:size
```

素材组装和验证脚本保留在 `scripts/` 中；一次性截图、运行记录与发布记录不包含在公开源码中。
