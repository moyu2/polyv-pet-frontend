# 狗狗逐帧素材 v2

当前观看页默认使用本目录。三阶段为 `egg`（幼犬）、`juvenile`（少年犬）、`adult`（成犬）；后端编码不变，显示文案按狗狗适配。

- 图集：2048×2464，8 列×11 行，单格 256×224，透明无损 WebP。
- 每阶段 74 个姿态：待机 6、右走 8、左走 8、问候 4、进食 8、开心 6、饥饿 6、休息 6、拖拽 6，以及 16 个注视方向。
- `manifest.json` 定义逐帧矩形、时长和循环方式；`*-poster.webp` 是同阶段静态回退。
- 仅复用 Codex 桌宠的逐帧制作方法，本目录为 `polyv-pet/2` 网页资源，不能直接作为 Codex 原生宠物安装。
- 左走按单帧镜像右走制作，角色无带方向含义的配件，毛色标记对称，帧顺序保持不变。
- 原 SVG 保留在上级 `dog/`，仅用于新图集和封面都失败时的同物种回退。

详细制作与验收记录见前端 `docs/狗狗桌宠-v2实现与验收.md`。
